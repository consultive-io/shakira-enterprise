Consultive General Customizations

A centralized, code-managed module for UI tweaks, view adjustments, report overrides, and Studio migrations to prevent loss during database upgrades.

✨ Included Customizations

🏷

45×35mm Lot Label (3-Up)

Custom paperformat rendering 3 sticker labels per sheet (45×10mm each) with Code128 barcodes, product name, and dynamic company branding.

🔒

MO Cancel Restriction

Restricts the Cancel button (action_cancel) on Manufacturing Orders exclusively to Manufacturing Managers (mrp.group_mrp_manager).

✍️

MO Component Operations

Explicitly allows create="true", edit="true", and delete="true" on the raw materials component list (move_raw_ids).

📂

Clean Extension Hub

Ready-to-use directory structure (views/, report/, data/) to add future XML view tweaks and studio migrations without creating new modules.

⚠

Important Setup Notice for Existing Databases

1. Lot Labels: If you previously edited stock.report_lot_label directly in the database interface, navigate to Settings > Technical > User Interface > Views, search for stock.report_lot_label, and click Compare / Reset to default so that the base template is clean and the module's inherited view handles the rendering.
2. Studio Views: If you have an active Studio customization on mrp.production.form (e.g. studio_customization.odoo_studio_mrp_prod_...), you can deactivate or delete it in Studio, as this module now formally maintains it in version-controlled code.

🛠️ How to Add Future Customizations

1
Add your XML file:

Place new view inheritance XML files inside cnslt_general_custom/views/ or reports inside cnslt_general_custom/report/.

2
Register in Manifest:

Add the new XML file path to the 'data' list in __manifest__.py and add any additional model dependency to 'depends' if needed.

3
Upgrade Module:

Run -u cnslt_general_custom via CLI or upgrade through Odoo's Apps dashboard.
