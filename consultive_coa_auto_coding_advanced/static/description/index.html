Chart of Accounts Auto Coding — Account Types

Configure a short code once for each account type, then generate a consistent Chart of Accounts structure from account type to group to account.

One consistent numbering scheme

This module extends Chart of Accounts Auto Coding with a level above Account Groups. The basic module generates account numbers; this module generates the group prefix from the chosen account type.

Account type 06 Two digits configured once
Account group 06001 Type code + three-digit group serial
Account 06001001 Group prefix + account serial

One-time configuration

Before creating coded groups, give each account type that you use a unique two-digit code.

  1. Open Accounting → Configuration → Account Type Coding.
  2. Find the account type, such as Expenses, Receivable, or Bank and Cash.
  3. Enter a unique two-digit value, for example 06 for Expenses.
  4. Save. New groups under that account type can now receive generated prefixes.
Automatic type list. The configuration list is seeded from Odoo's live Account Type selection. Types added by Odoo or another installed module are included automatically.
Choose carefully. After groups are created under a type, its two-digit code is locked. Changing it would make existing group and account numbers inconsistent.

Create an Account Group

What you do

  1. Open Accounting → Configuration → Account Groups.
  2. Create a group, for example Office Expenses.
  3. Choose its Account Type.
  4. Save the group.

What Odoo does

For an Expenses type configured as 06, the first group receives 06001. The next one receives 06002.

The generated value is written to the start prefix, end prefix, and Coding Prefix, so core Odoo grouping and automatic account coding use the same value.

Independent counters. Each account type has its own group sequence. Creating an Expenses group does not change the next Income group number.

Create an Account

  1. Open Accounting → Configuration → Chart of Accounts and create an account.
  2. Choose Type using Odoo's standard grouped selector: Balance Sheet / Profit & Loss, then Assets, Liabilities, Income, Expense, and so on.
  3. Choose a Coding Group. The list only contains groups matching the selected Type and allowing automatic coding.
  4. Review the Next Code preview, then save.

For a selected Coding Group 06001, the first new automatic account is issued 06001001; the next becomes 06001002.

Code, Next Code, Coding Group, and Group

Field Meaning Example
Code The account's current saved code. Existing or imported accounts keep this value unless you explicitly regenerate it. 990001
Next Code A preview of the next code that automatic allocation would issue from the selected Coding Group. 01002001
Coding Group The group selected to drive automatic code allocation. 01002 test
Group Odoo's standard computed group. It comes from the code prefix when possible; if a retained legacy code has no matching prefix, it falls back to the selected Coding Group. 01002 test
Existing accounts are safe. Assigning a Coding Group does not silently renumber an existing account. For an unused account that you want to standardise, use Regenerate Code. Odoo refuses regeneration once journal items exist.

Changing a group's Account Type

A group can be moved to another Account Type only while no accounts use its current prefix. The group is then assigned the next prefix below the new type.

For example, a group may move from Expenses 06001 to Income 04001. Once accounts exist under 06001, create a new group instead; renumbering used accounting codes is an audit decision.

Multi-company and imports

Multi-company

Account Type Coding records are shared, while the two-digit code is configured per root company. Each company can therefore number its chart differently.

Imports and templates

The standard Odoo Type field remains supported at ORM level. Chart templates and imports that set the standard account type directly continue to work.
